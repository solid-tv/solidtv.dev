Write JSX. Render WebGL.

If your team knows React or SolidJS, they already know SolidTV. Components compile straight to renderer nodes, so there is no virtual DOM and no DOM at all between your code and the GPU.

  • ✓ Remote-control focus and navigation handled by Row and Column
  • ✓ Focus states and transitions declared in a style object
  • ✓ Fine-grained updates: only the node that changed is touched
import { For } from 'solid-js';
import { Row } from '@solidtv/solid/primitives';

const posterStyle = {
  width: 240,
  height: 360,
  borderRadius: 16,
  scale: 1,
  transition: { scale: true },
  $focus: { scale: 1.1 },
};

const Rail = (props) => (
  <Row gap={24} autofocus>
    <For each={props.movies}>
      {(movie) => (
        <view src={movie.poster} style={posterStyle} />
      )}
    </For>
  </Row>
);

FAQ

Frequently asked questions

Which TV platforms does SolidTV support? +

SolidTV runs on any device with a modern web browser (Chrome 38+), including Samsung Tizen, LG WebOS, Android TV (Sony, Philips, Panasonic, TCL), Amazon Fire TV, Panasonic, and select set-top-boxes. Apple TV (tvOS) is supported through NativeScript. The one exception is Roku, which only runs apps written in its own BrightScript language.

How does SolidTV run on Apple TV? +

Through NativeScript, without a browser or WebView. NativeScript is the runtime, its canvas plugin provides the WebGL surface, and the @solidtv/nativescript package connects the renderer, the Siri Remote and the app lifecycle. Your app's web entry point is imported unchanged. Read how it works, or follow the deployment guide.

How does SolidTV compare to LightningJS? +

SolidTV delivers roughly 50% higher FPS than LightningJS on equivalent hardware, eliminates layout jitter via Atomic First Paint, and is approximately 12kb minified + gzipped. See the full comparison.

Is SolidTV open source? +

Yes. SolidTV is released under the Apache 2.0 license and developed in the open on GitHub. The SolidTV Renderer and the NativeScript host are published on npm under the same license.

Do you offer commercial support for SolidTV? +

Yes. Support plans give your team priority answers, a private support channel, priority bug fixes and upgrade guidance. We also offer fixed-scope performance audits, migration assessments, Apple TV ports, custom development and team training. See support & services.

Can you help if our TV app isn't built with SolidTV? +

Yes. Performance audits and consulting cover any web-based TV app, including LightningJS, Blits, React and Vue apps running on Tizen, WebOS, Android TV and Fire TV.
